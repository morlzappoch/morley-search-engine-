# Security Policy

## Scope

Morley Hub organizes project metadata and provenance records.

## Reporting

Do not publish suspected vulnerabilities, credentials, private keys, financial information, or confidential evidence in GitHub issues.

Use GitHub Security Advisories/private disclosure where available.

## Evidence preservation

For alleged IP or security incidents, preserve original files, timestamps, repository history, hashes, access logs, and other verifiable evidence.

Never upgrade a provenance status from `user_claim` to `documented` or `externally_verified` without supporting evidence.
